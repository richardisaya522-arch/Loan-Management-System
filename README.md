# ANTHONY MICROFINANCE - LOAN MANAGEMENT SYSTEM

Mfumo wa kukopesha (Flask + SQLite)

## Kuendesha
```
pip install -r requirements.txt
python app.py
```
Fungua http://127.0.0.1:5000

- **Wateja:** bonyeza *Jisajili*, kisha ingia kwa namba ya simu na password, na uombe mkopo.
- **Ofisi (admin):** `admin` / `admin123` (badilisha kwa `ADMIN_PASSWORD=... python app.py` kabla ya mara ya kwanza).

## Mtiririko
Mteja anajisajili -> anaomba mkopo -> admin anakagua kwenye *Maombi* (idhinisha na kuweka riba, au kataa)
-> mkopo unaanza -> admin anarekodi malipo -> mteja anaona ratiba, deni na risiti zake.
